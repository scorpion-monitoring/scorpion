The blocking items of the backlog (M12a, sprint 5). **Rate limit:** a signed-in person's ordinary requests now count against their own session, so people behind one address no longer share a budget of 120 and one person clicking through a page can no longer lock themselves out; the address stays a larger ceiling, and anonymous callers, tokens and the sign-in routes are limited as before (changing the month of the data-submission page eight times in a minute used to fail, nine in a row now work, and that page reads its reference data once per visit). **Audit trail:** every successful sign-in (password or OIDC) is an entry, and the failed sign-ins of one name in one window (setting `loginThrottle.auditWindowSeconds`, default one hour) are one entry with a count; nobody is locked out and no name, address or password is stored. **Tokens:** a member of a provider can now make a working token for `POST /api/v1/measurements` from the profile page (the write scope implies the permission to submit; the owner still has to be allowed). **Reporting reminder:** it is sent on the configured day or on the first run after it, once per provider and month. **Public API v1 (additive):** the list filters of `GET /services` also take a repeated parameter (`provider=A&provider=B`), so an organisation abbreviation with a comma can be asked for.
