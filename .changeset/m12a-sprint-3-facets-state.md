The search of the service catalogues (`/services` and the public `/catalog/services`) searches as you type: there is no Search button any more, Enter still sends at once, and a typed search is one step back in the browser's history. A line above the table says how many services match, and screen readers hear it after every change. When the text matches no service name but a filter value (for example a provider), the line offers that filter. The removable filter badges above the table are gone: each chosen filter is shown once, as its checked box. Addresses of filtered lists (`?q=&f.<facet>=<value>`) are unchanged, and so are the API and its answers.
