M7 sprint 4: the service catalogue. A new page `/services` (in the main navigation, for every signed-in person) lists the services in a table with the service's icon and name, its provider, its consortia as badges and its stage, with sorting by service, provider or stage, 10, 20 or 50 rows to a page, a search by name or slug, facets with counts and removable filter badges. The search, the filters, the sort and the page are in the address, so a filtered list can be bookmarked and shared. Each facet counts over the services that the search and all the other facets leave, so a person sees what one more choice would give; a value with no service in that set is shown with 0 only when it is chosen, and the services that have no licence or no consortium are one choice of their own ("Unknown", "No consortium"). A service always appears once, whatever its number of consortia, and a service with none appears too; this closes the legacy defect in which every service was in every consortium (regression test `defect-02.service-consortium.test.ts`). API: `GET /api/internal/services` takes repeatable filters by facet (`consortium`, `stage`, `license`, `provider`, and the id of any facet another module contributes), `sort` (`name`, `slug`, `stage`, `provider`), `dir` and `locale`, and its rows now carry `provider` and `consortia` instead of the flat `organisations` list (an internal route, not the public API v1); the new `GET /api/internal/services/facets` takes the same filters and returns the facets with their counts. A filter value that names nothing (an organisation, stage or licence that does not exist, or a made-up filter) is a 422, never an empty list. Another module can add a facet by contributing to the registry `service.facet` (a value kept in the service's fields needs one call, `fieldValueFacet`); the shape of that entry changed in this release, and no module contributed one yet. The pages for creating a service and for one service arrive in the next releases; until then the catalogue shows names without links. A page's loader now receives the caller's language.
