The start page now shows a dashboard of widgets that every signed-in person can arrange. A button at the bottom right ("Customise dashboard") turns on edit mode and opens a menu of the widgets you may add (the membership requests, the registrations waiting for approval and the mail that could not be delivered, for the people who may see them); in edit mode every widget can be moved, resized and removed with buttons, with the keyboard or by dragging, and "Reset to default" shows the default dashboard again. Changes are saved a second after the last one, for your own account only, and come back after a reload; a widget you may no longer see is left out with a message and returns with the permission. If your account may not store preferences, the page says the dashboard cannot be saved and keeps the layout until you leave it. Below the tablet width the widgets are stacked and cannot be dragged. German and English texts are included, and the keyboard drag is announced in the page's language. The grid libraries (Snapgrid 0.12.0 and dnd-kit 0.5.1) are new runtime dependencies of the web app, loaded only on the start page; the image grows by about 18.6 MB, most of it the Svelte package that they list as a peer, and the page's JavaScript by about 174 kB (47.9 kB gzip for the grid itself). No API route changed and the public v1 API is unchanged.
